PROJECT INTELLIGENCE

FROM PIXELS
TO DECISIONS.

SiteWise AI is designed as a multi-stage deep-learning pipeline for satellite-image analysis.

The first model performs land classification using an EfficientNetB0 architecture. Its output contains both the predicted land type and probability distribution across the supported land classes.

SiteWise then extracts eight visual features from the image. These features describe characteristics such as vegetation, water presence, brightness, built-up regions and road-like structures.

The second recommendation stage combines these visual features with the land-class probability vector. Model 3 produces project-defined suitability scores for multiple potential site uses.
